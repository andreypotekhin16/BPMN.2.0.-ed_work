# Моделирование бизнес-процесса: Открытие платёжного счёта в банке (BPMN 2.0)

## Описание задачи
Моделирование бизнес-процесса открытия платёжного счёта в банке с использованием нотации BPMN 2.0.

## Что сделано
- Построен основной поток процесса открытия счёта
- Добавлен альтернативный сценарий (отказ в открытии счёта)
- Использованы:
  - Стартовое и конечное события
  - Задачи (Tasks)
  - Шлюз (XOR Gateway)
  - Сообщения (Message Flows)
  - Дорожки (Lanes): Клиент / Банк
